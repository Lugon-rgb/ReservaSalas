# ReservaSalas
WebApp para reserva de salas de estudo

## Database migrations

Install the project dependencies and create the schema:

```bash
pip install -r requirements.txt
flask --app run db upgrade
flask --app run seed-data
```

`seed-data` loads the development fixtures defined in `reservaSalas/acesso/routes.py`.
It can be run again without duplicating matching fixture records.

When a model changes, create and review a migration, then apply it:

```bash
flask --app run db migrate -m "Describe the schema change"
flask --app run db upgrade
```

All models registered on the shared SQLAlchemy `db` metadata are included in
autogenerated migrations. For a database created before migrations were added,
back it up and replace the old development database before running the initial
`db upgrade`; the initial migration expects an empty schema.
